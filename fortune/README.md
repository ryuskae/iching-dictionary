# 간지괘운

양력 생년월일시를 한국천문연구원 음양력 기준 사주 네 기둥으로 변환하고, 참조표의 60갑자–주역괘 대응에 따라 연·월·일·시의 괘 조합을 계산하는 정적 웹앱입니다.

## 계산 규칙

- 연주는 음력 설날에, 월주는 음력 월이 바뀔 때 간지가 달라집니다. 월지는 음력 1월을 인월로 잡고, 월간은 오호둔으로 뽑으며, 윤달은 앞 달의 간지를 그대로 씁니다. 일주와 시주는 lunar-javascript의 계산을 그대로 씁니다.
- 사주의 연주·월주·일주·시주를 각각 참조표의 괘로 바꿉니다.
- 선택한 기간의 간지를 같은 표에서 괘로 바꿉니다.
- `사주 괘의 상괘 + 기간 괘의 하괘` 네 개를 계산합니다.
- `기간 괘의 상괘 + 사주 괘의 하괘` 네 개를 계산합니다.
- 여덟 괘의 출현 횟수를 합산해 표시합니다.
- 평생 운은 서로 다른 두 주를 골라 한 주의 상괘와 다른 주의 하괘를 결합합니다. 사주가 네 주면 12개, 출생 시각이 없어 세 주면 6개 조합이 나옵니다.

여러 인물의 이름과 생년월일시는 `localStorage`에만 저장되며 외부 서버로 전송되지 않습니다. 출생 시각은 선택 사항이며, 입력하지 않으면 연주·월주·일주만 사용합니다. 간지 계산에는 MIT 라이선스의 [lunar-javascript](https://github.com/6tail/lunar-javascript)를 사용합니다.
