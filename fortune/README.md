# 간지괘운

양력 생년월일시를 절기 기준 사주 네 기둥으로 변환하고, 참조표의 60갑자–주역괘 대응에 따라 연·월·일·시의 괘 조합을 계산하는 정적 웹앱입니다.

## 계산 규칙

- 사주의 연주·월주·일주·시주를 각각 참조표의 괘로 바꿉니다.
- 선택한 기간의 간지를 같은 표에서 괘로 바꿉니다.
- `사주 괘의 상괘 + 기간 괘의 하괘` 네 개를 계산합니다.
- `기간 괘의 상괘 + 사주 괘의 하괘` 네 개를 계산합니다.
- 여덟 괘의 출현 횟수를 합산해 표시합니다.

생년월일시는 `localStorage`에만 저장되며 외부 서버로 전송되지 않습니다. 간지 계산에는 MIT 라이선스의 [lunar-javascript](https://github.com/6tail/lunar-javascript)를 사용합니다.
